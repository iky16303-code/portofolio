IKY — DIGITAL PORTFOLIO
=======================

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder iky_portfolio.
3. Buka index.html di browser (Chrome disarankan).

Untuk publikasi:
- Upload isi folder ini ke GitHub repository.
- Aktifkan GitHub Pages dari Settings > Pages.
- Pastikan index.html berada di root repository.

Catatan:
- Koneksi internet diperlukan untuk Google Fonts.
- Tombol Spotify membuka lagu di Spotify; pemutaran mengikuti aplikasi/browser dan akun Spotify.
- Kartu identitas dapat diseret dengan mouse atau jari untuk diputar. Ketuk sekali untuk membalik sisi kartu.
- Bagian pencapaian ditulis sebagai milestone personal, bukan penghargaan resmi.
